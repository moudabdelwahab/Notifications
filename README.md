# Telegram Mention Notifier

تطبيق ويب متقدم لمراقبة إشارات وردود تيليجرام مع إرسال إشعارات فورية عبر البريد الإلكتروني.

## الميزات

✅ **تسجيل دخول آمن** - تسجيل دخول مع Google عبر Supabase
✅ **مراقبة الإشارات** - تابع جميع الإشارات (@username) في المجموعات والقنوات
✅ **مراقبة الردود** - اكتشف الردود على رسائلك الشخصية
✅ **إشعارات فورية** - استقبل إشعارات بالبريد الإلكتروني فوراً
✅ **لوحة تحكم سهلة** - واجهة بسيطة وسهلة الاستخدام
✅ **إعدادات متقدمة** - تحكم كامل بإعدادات المراقبة

## البدء السريع

### 1. فتح التطبيق
ما عليك سوى فتح ملف `index.html` في متصفحك أو نشره على خادم ويب.

### 2. تسجيل الدخول
انقر على زر "تسجيل الدخول مع Google" وقم بتسجيل الدخول باستخدام حسابك على Google.

### 3. إعداد Telegram
1. انتقل إلى [my.telegram.org](https://my.telegram.org)
2. قم بتسجيل الدخول برقم هاتفك
3. انقر على "API development tools"
4. أنشئ تطبيقاً جديداً وانسخ API ID و API Hash
5. عد إلى التطبيق والصق البيانات

### 4. تفعيل المراقبة
بعد إدخال بيانات Telegram، فعّل المراقبة من لوحة التحكم.

## البنية التقنية

### الواجهة الأمامية
- **HTML5** - هيكل الصفحة
- **CSS3** - التصميم والحركات
- **JavaScript** - التفاعل والعمليات

### قاعدة البيانات
- **Supabase** - إدارة البيانات والمصادقة
- **PostgreSQL** - قاعدة البيانات الأساسية

## الأمان

- جميع البيانات محمية بـ Row Level Security (RLS)
- بيانات Telegram API محفوظة بشكل آمن
- جميع الاتصالات مشفرة (HTTPS)
- لا يتم تخزين كلمات المرور
